Admin path: Admin → Services → Create service
  → Open service detail → Create offering → Configure offering

Offering wizard steps (all must be complete before Activate):
  1. Details      — name, dates, visit location/instructions, applicant fields
  2. Eligibility  — rules (optional)
  3. Documents    — required uploads
  4. Workflow     — steps (Staff / AI / Student handlers)
  5. Queue        — queue_only | appointment_only | hybrid + payment config
  6. Review       — check completeness → Activate

After activation the service becomes Active (visible to students).
