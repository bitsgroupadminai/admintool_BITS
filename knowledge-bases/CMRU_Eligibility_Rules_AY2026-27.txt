PURPOSE
This document states eligibility criteria for admissions offerings so the admin
tool can extract structured rules:
  { field, fieldType, operator, value, documentExcerpt }

RULES FOR EXTRACTION
- All listed rules for an offering use AND logic.
- fieldType is one of: numeric | text | boolean
- operator is one of: eq | neq | gte | lte | gt | lt
- value for numeric fields is a number (percentage without the % sign in value)
- documentExcerpt must be a short direct quote from this document
- Extract ONLY rules listed under the matching Offering Name

COMMON NOTE
Reserved category relaxation (where stated): use the reserved value when the
applicant claims an eligible reserved category with valid certificate.
